# ZAUM — демо сервиса для работы с блогерами

Статический прототип по демонстрационной таблице ZAUM. Откройте `index.html` в браузере или разместите файл на статическом хостинге.

Данные вымышленные, включены в файл как статичный срез; автоматической синхронизации нет. Исходная таблица не изменяется. Поиск работает по имени, площадке, формату и артикулу; доступны фильтры статуса и наличия просмотров, карточки партнёров и переход между ними.

Далее: импорт и обновление данных из собственной копии таблицы, фильтры по датам и площадкам, сравнение результатов и контроль доступа.
